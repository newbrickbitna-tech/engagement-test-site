# Engagement Test Site

웹 방문 기록(page view, form submit)이 Salesforce Data Cloud를 거쳐 Lead·Contact 단위로 보이는지 확인하는 테스트용 정적 사이트입니다. 실제 서비스가 아니며 검색 엔진 색인을 막아 두었습니다.

- `assets/config.js`: SDK 스크립트 URL 설정
- `assets/tracking.js`: SDK 초기화, page view, 폼 제출 시 identity 이벤트
- 페이지: `index.html`, `product.html`, `contact.html`, `thank-you.html`
